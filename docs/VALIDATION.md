当前保持实验版，发行清单中的 `manualAcceptance=false`，本机完整人工通过标记未设置。Workspace 自动打开仍为 `unsupported`，手动 Workspace 通过不会改变这个能力。

清理本地时保留已登录的 Profile 数据、宿主桥接目标与当前 Workspace。旧发布包可以在 GitHub 保留后删除；删除注册回调所指向的旧包前，必须先将处理器更新到保留的新包。
