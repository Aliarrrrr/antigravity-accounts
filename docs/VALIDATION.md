## 发布状态与后续验收

当前保持实验版，发行清单中的 `manualAcceptance=false`，本机完整人工通过标记未设置。Workspace 自动打开仍为 `unsupported`，手动 Workspace 通过不会改变这个能力。

本轮按用户指令跳过 SSH 实际连接，不再继续。日常 Chrome 的真实登录回调已在本轮整改便携包验收通过；强停后的登录保留和当前文件编辑入口仍未明确确认，完整人工验收未完成。仅在 [人工验收计划](../NEXT_MANUAL_TEST_PLAN.md) 的适用项目证据完整后，由用户明确设置 `compatibility accept --manual-passed`；发行流水线不得自动设置。

清理本地时保留已登录的 Profile 数据、宿主桥接目标与当前 Workspace。旧发布包可以在 GitHub 保留后删除；删除注册回调所指向的旧包前，必须先将处理器更新到保留的新包。
