# Project history

This repository was renamed from `antigravity-profile-hub` to `antigravity-accounts` for the Accounts 0.4.0-preview.8 release. Its active tree now contains the native model-menu account plugin and its required Windows host adaptation.

Earlier Profile Hub versions managed separate application profiles and included Next CLI, WPF and experimental Rust interfaces, protocol handling, configuration inheritance and shared-workspace experiments. Those applications are no longer built or included in Accounts packages. Their source remains in Git history, including [the tree before this reorganization](https://github.com/Aliarrrrr/antigravity-accounts/tree/00ddfb120ef1f4d032e4b81a450c62ff24d9e9c2).

Existing historical tags and releases retain their original names. Older Profile Hub releases are different applications; use the [Accounts release](https://github.com/Aliarrrrr/antigravity-accounts/releases/tag/accounts-v0.4.0-preview.8) for the native account-menu plugin. Accounts does not migrate Profile Hub logins, authentication databases or conversations.

The [public technical overview](ACCOUNTS_PUBLIC_OVERVIEW.md) and [Marketplace request](ACCOUNTS_MARKETPLACE_REQUEST.md) record the October 2026 preview.5 submission. They describe that submission's implementation and checks; current installation and validation scope are documented separately.
