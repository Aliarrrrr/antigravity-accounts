2026-10-29，preview.5 通过 [Antigravity Plugin Interest Form](https://forms.gle/2EX5RFYPoJe1UgxR9)提交收录与接口请求，页面显示“您的回复已记录”。这确认申请已提交，不代表审核通过、已上架或所需接口已获支持。

发布者为 Aliarrrrr (Independent developer)。联系邮箱按用户指定填写于申请表，不写入本仓库。没有向表单上传程序、源码或本地账号检查记录。

## 当时提交的技术说明

[公开 Gist](https://gist.github.com/Aliarrrrr/a2070ce7fb58c2f05c308ec64096990e)在提交时与用户批准的 preview.5 正文一致。[归档正文](ACCOUNTS_PUBLIC_OVERVIEW.md)保留当时说明，文件顶部另有归档提示；不据此声称当前文件整体与公开 Gist 逐字相同，也未在本次发布中更新 Gist。

当时说明的检查对象为 Antigravity 2.28.1 与 Accounts 0.4.0-preview.5，包括两次真实账号元数据切换、原生菜单及模型选择保留。代理模型请求为 0；真实生成、扣额、到期续期及跨账号继续生成未验证。该结果不能直接作为后续版本的运行结果。

## 请求的接口与确认事项

- 原生模型菜单中的账号分组注册。
- 原生模型与额度请求所用身份的选择。
- 工作空闲判断、身份刷新及原模型选择保留。
- 独立开发者的标准安装、更新及 Marketplace 收录方式。
- 使用匹配桌面程序公开 OAuth 客户端配置进行第三方分发是否允许，或是否需要单独注册客户端。
