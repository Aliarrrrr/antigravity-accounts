# Antigravity Accounts

在官方工作界面的模型列表中按账号选择用量。账号通过官方 Google 网页授权，独立 .NET 组件保存用户主动添加的登录，官方语言服务直接请求 Google。项目、会话与工具执行继续由官方 App 负责。

当前源码为 **0.4.0-preview.7**，已安装到 Antigravity App **2.28.2**。账号分组、添加账号与切换状态放在原生模型列表内；不再创建独立账号窗口。组件采用自包含单文件压缩，无需另装运行时。preview.6减少了对话文本更新引起的模型菜单扫描；preview.7更新原生程序精确匹配。2.28.2官方更新曾移除preview.5接入，本轮已恢复原生3个账号分组、中文界面及原项目、会话、模型和托盘设置；没有新增账号切换，模型请求为0。

preview.3 曾安装到 2.26.0 并显示账号分组，但一次账号确认失败且未返回具体代码；2026-10-29 官方更新到 2.27.0 已移除旧适配。preview.4已在2.27显示3个账号分组，代理未执行账号切换。preview.5适配官方2.28，切换凭据前保存各窗口模型，处理后台账号刷新先覆盖默认模型的情况；已安装到2.28.1并完成两次真实账号元数据切换，恢复原账号、项目与模型，App/语言服务/组件未重启；模型请求为0。它仍包含版本限定的 Electron 宿主适配，标准 `plugin.json` 本身不会加载模型菜单和 HostAuth。市场收录及后续版本自动兼容尚未完成；2026-10-29已提交官方收录与标准接口申请，表单确认收到，待Google回复。

## 当前实现

- 未添加独立账号时直接进入原工作界面，插件作为本机账号管理入口加载。
- 设置唯一主账号；其余主动添加的账号显示为附属用量账号，不复制原生会话。
- 运行期切换包含暂存新提交、等待原生任务、提交账号和确认身份；原生副本的假账号同进程 A→B 检查属于前版结果，preview.7本轮没有执行账号切换。
- 独立账号模式使用单独生成的 LS 程序副本，在读取项目时先刷新身份，避免旧项目与新凭据混用。原登录模式不使用这项项目查询改动。
- 使用匹配安装程序的公开桌面 OAuth 配置，在浏览器主动授权添加账号。
- Windows DPAPI CurrentUser 加密独立账号存储；公开账号列表和面板不返回 token。
- 通过本地 HostBridge 提供独立账号凭据；不读取原官方认证文件，不接收原 Google Authorization，不代理推理请求。
- 已启用独立账号后，授权准备失败会停止 LS 启动，不会静默沿用原账号。
- 当前账号组下保留官方模型选项，其他账号显示为折叠分组；账号操作继承原生主题和字体，不再携带独立 HTML/CSS 面板。
- 菜单关闭时不轮询；授权或切换待完成时才读取本机状态。切换提交后确认失败，可在当前账号组重新确认。
- 托盘账号入口打开原生模型菜单；启动所选账号失效时，用系统对话框选择已有账号或重新授权。

同进程切换、临界期间到达的新请求、取消等待后外部任务继续运行的检查属于前版原生程序副本。真实账号元数据来回切换分别在preview.2/2.26.0和preview.5/2.28.1完成；preview.7本轮只检查2.28.2启动与原生菜单。实际额度扣减、到期续期及原生会话跨账号生成内容尚未确认。

## 安装与源码

见 [插件说明](docs/ACCOUNTS_PLUGIN.md)，其中列出安装、独立授权、恢复和未确认项。源码构建使用 .NET SDK 10.0.400：

```powershell
./scripts/Publish-Accounts.ps1 -DotNet '<SDK目录>/dotnet.exe'
```

插件发布不包含旧 WPF 管理器或官方程序二进制。安装时才在本机生成对应的程序适配，保留原程序用于恢复。已有项目、旧 Profile 和原账号登录数据不迁移。

| 目录 | 内容 |
| --- | --- |
| `src/Antigravity.Accounts` | 独立 OAuth、加密存储与 stdio 组件 |
| `packages/account-plugin` | 系统启动恢复、公开 OAuth 配置读取、安装入口 |
| `packages/hostauth-adapter` | 2.28.2 宿主接入、程序副本生成与恢复 |
| `tests/Antigravity.Accounts.Tests` | 不访问真实账号的组件行为测试 |

旧多开工具保留为兼容代码，其使用说明移至 [旧 Profile Hub 文档](docs/LEGACY_PROFILE_HUB.md)；以前的 [共享工作空间说明](docs/SHARED_WORKSPACES.md) 与 [验证记录](docs/VALIDATION.md)仅对应各自注明的实现，不证明本插件的原生认证行为。
